# Exercício 6 – Quiz Geek

Atividade da disciplina **Usabilidade em Desenvolvimento Web, Mobile e Jogos** — Lista de Exercícios de Desenvolvimento Web.

## Enunciado

Criar um quiz simples com 3 perguntas.

## Requisitos atendidos

- [x] 3 perguntas sobre cultura geek (Star Wars, Naruto e Marvel)
- [x] Opções de resposta
- [x] Feedback de acerto/erro em cada pergunta (mostrando a resposta certa)
- [x] Pontuação final com mensagem personalizada e opção de jogar de novo

## Tecnologias

HTML5, CSS3 e JavaScript

## Como executar

Abra o arquivo `index.html` no navegador ou acesse a versão publicada no GitHub Pages:
https://rogeroliveira1.github.io/usabilidade-web-06-quiz-geek/
